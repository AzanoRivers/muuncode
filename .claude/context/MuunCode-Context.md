# Project

**MuunCode**

MuunCode is an Open Source Embedded Development Platform designed to radically simplify firmware development by allowing developers to build embedded applications using familiar Web technologies.

The long-term vision is to enable anyone who knows HTML, CSS and JavaScript to create native applications for physical devices quickly, intuitively and without the traditional complexity of embedded development.

---

# Vision

MuunCode believes that creating technology should feel as natural as building a website.

Modern developers should spend their time creating ideas instead of configuring toolchains.

The platform exists to remove unnecessary complexity while preserving native performance.

Our philosophy is simple:

> Build incredible things, faster.

---

# Mission

Make Embedded Development accessible to millions of Web Developers.

Allow developers to focus on solving real-world problems instead of learning dozens of embedded-specific tools.

MuunCode should dramatically reduce the learning curve of firmware development without sacrificing performance or flexibility.

---

# Core Principles

Every architectural decision should prioritize:

- Simplicity
- Developer Experience
- Predictability
- Performance
- Native Output
- Strong Validation
- Extensibility
- Open Source
- Long-Term Maintainability

When multiple solutions exist, always prefer the one that makes the platform easier to understand for new developers.

---

# Philosophy

MuunCode does not try to teach developers Embedded Programming.

MuunCode brings Embedded Programming closer to the knowledge developers already have.

Developers should feel they are creating applications, not configuring firmware.

The platform should encourage experimentation, rapid prototyping and creativity.

The ideal experience should feel closer to modern Web Development than traditional Embedded Development.

---

# Technology Philosophy

MuunCode should always adopt modern technologies whenever they provide a better developer experience.

Before adopting any dependency, evaluate:

- Active maintenance
- Modern architecture
- TypeScript support
- Modular design
- Performance
- WebAssembly compatibility
- Long-term sustainability

Avoid legacy technologies when modern alternatives exist.

Developer Experience has higher priority than legacy compatibility.

---

# Non Goals

MuunCode is NOT:

- A JavaScript runtime for microcontrollers.
- A browser running inside an ESP32.
- A replacement for ESP-IDF.
- A replacement for FreeRTOS.
- A replacement for GCC or Clang.
- A replacement for CMake.
- A replacement for LVGL.
- A replacement for GitHub.
- A Git hosting platform.
- A cloud storage platform.
- A no-code builder.
- A visual programming tool.

MuunCode generates native embedded projects.

The generated firmware should remain compatible with official embedded SDKs whenever possible.

MuunCode should leverage existing ecosystems instead of replacing them.

The platform exists to simplify development, not to reinvent proven embedded technologies.

---

# Future Mindset

Every feature added to MuunCode should answer one question:

"Does this help developers create incredible things faster?"

If the answer is no, the feature probably does not belong in MuunCode.
